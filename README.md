# Formulario de Pre-Aprobación — MGG Panamá

Public 4-step vehicle pre-approval form (`/`) and a review panel (`/admin`), built for Jet Admin.

```bash
npm install
npm run dev      # local dev
npm run build    # type-check + production build
```

Jet setup (table columns, storage, submit workflow, emails, admin users): see [docs/JET_SETUP.md](docs/JET_SETUP.md).
Code map and conventions: see [AGENTS.md](AGENTS.md).
